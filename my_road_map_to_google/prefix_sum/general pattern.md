
Your interview cheat sheet :- 
Problem wording	First thought
Range sum queries	Prefix Sum
Count subarrays with sum K	Prefix Sum + HashMap
Find subarray with sum K	Prefix Sum + HashMap / Set
Sum = 0	Prefix Sum
Positive numbers + sum constraint	Sliding Window
Positive + negative + exact sum	Prefix Sum
"How many subarrays?" + exact sum	Prefix Sum + frequency map
Product instead of sum	Usually not Prefix Sum; inspect for logs/sliding window/etc.
