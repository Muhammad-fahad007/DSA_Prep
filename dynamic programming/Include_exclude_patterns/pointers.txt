various different patterns

Subset Sum
Target Sum

Take current item OR skip it
State usually:
(index, remaining_capacity)

2. Sequence Matching DP
Examples:
LCS
Edit Distance
Pattern:
Compare two sequences
State:
(i, j)

3. Increasing/Subsequence DP
Examples:
LIS
Russian Doll Envelopes
Pattern:
Can current extend previous?

4. Interval / Partition DP ← MCM belongs here
Examples:

Burst Balloons
Merge Stones
Boolean Parenthesization
Pattern:
For a RANGE,
try every SPLIT point.
